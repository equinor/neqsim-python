# NeqSim Python 3.20.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the NeqSim Java 3.20.0 engine for Java 17 or newer.
- Component database integrity fixes: repaired component identities in
  `COMP.csv`, corrected rows that held another substance's properties, and
  added an integrity gate to keep them correct.
- Repaired the UNIFAC group tables. A component with no UNIFAC groups now fails
  loudly instead of silently producing `NaN`.
- Fixed two overloads that silently discarded arguments: `addTBPfraction2` no
  longer discards the boiling point, and `addTBPfraction` no longer discards
  the acentric factor.
- Component synonyms are now resolved in `Phase.getComponent`.
- Retains Python 3.10–3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.20.0
```

Use conda when you want OpenJDK installed with the package:

```bash
conda install -c conda-forge neqsim=3.20.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```
