# NeqSim Python 3.29.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the official NeqSim Java 3.29.0 release engine for Java 17 or newer.
- Thermodynamics and flash: speeds up CPA association solving and cubic phase
  classification, recovers free water below the overall-water screen, corrects
  LBC viscosity pseudo-critical mixing, and preserves phase state and
  composition across zero stream flow.
- Reservoir and PVT: extends fixed-cell depletion with dry and wet-gas phase
  transitions and conserved-inventory Gibbs comparisons, stabilizes aquifer
  influence functions, and adds OLGA PVT table options (configurable grids,
  produced water, salinity) and a forward PVT proxy surface process generator.
- Electrolytes and chemistry: adds an exact-source reactive carbonate mode for
  Pitzer brines, solid-gas reaction equilibrium (FeS/FeCO3), and reservoir H2S
  mineral-buffer screening.
- Process equipment and dynamics: adds compressor power-train integration with
  turbine and electric drivers, conservative separator energy integration,
  dynamic heat-exchanger control workflows, reference water and seawater
  cooling properties, and gas-turbine installation pressure-loss corrections.
- Pipelines and networks: improves two-fluid restart, terrain low-point pool
  reporting, pig position events and gas-inventory coupling, and atomic
  algebraic-junction network solving.
- Engineering drawings and safety: connects ESD/HIPPS and PSV responses and
  compressor automation to DEXPI P&IDs, links System Control Diagrams, and runs
  safety scenarios across process models. Review drawings still require
  engineering verification.
- Fixes: distillation columns are no longer reported solved while internal flows
  are still changing, `.neqsim` files are stamped with the real NeqSim
  version, DEXPI import handles standard Proteus XML, and the n-decane molar
  mass in the ISO 6976 constants is corrected.- Refreshes the bundled Java API manifest, type stubs, and component-name
  metadata for the 3.29.0 engine.
- Retains Python 3.10-3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.29.0
```

The matching conda-forge package can be installed once it is published:

```bash
conda install -c conda-forge neqsim=3.29.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```

## Quick Start

```python
from neqsim.thermo import TPflash, fluid, printFrame

natural_gas = fluid("srk")
natural_gas.addComponent("methane", 0.85)
natural_gas.addComponent("ethane", 0.10)
natural_gas.addComponent("propane", 0.05)
natural_gas.setTemperature(25.0, "C")
natural_gas.setPressure(60.0, "bara")
natural_gas.setMixingRule("classic")

TPflash(natural_gas)
printFrame(natural_gas)
```
