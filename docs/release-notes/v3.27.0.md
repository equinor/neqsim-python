# NeqSim Python 3.27.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the NeqSim Java 3.27.0 engine for Java 17 or newer.
- Compressors: chart-mode compressors now honor the selected polytropic
  method, head inversion tolerance scales for tiny shaft duties, wet-gas energy
  increments are resolved differentially, and a fixed-speed operating point
  classifies recycle, throttling and head-deficit cases. Shaft groups,
  driver-limited throughput, gas-turbine site rating and a platform power system
  are added.
- Thermodynamic fixes: `Component.getCpD()` returns the stored coefficient
  without the former `1e-10` offset, so ideal-gas heat capacity and enthalpy
  shift slightly (for example, the gas enthalpy of a methane/water SRK flash at
  280 K and 10 bara changes by about 0.01 %). Latent heat coefficients are
  reconciled, GERG-water temperature derivatives are consistent, trace-water CPA
  dew points are solved, PH flash iteration stops on residual stall, and PR-CPA
  caloric consistency is restored.
- Pipeline and network: signed-face outlet thermodynamics, two-fluid node energy
  and source conservation, VFPPROD table-driven hydraulics, a `TwoFluidPipe`
  liquid holdup calibration multiplier, and experimental Safety Shutdown valve
  travel and acoustics models.
- Process and dynamics: an opt-in run watchdog for `ProcessSystem` and
  `ProcessModel`, transactional valve actuators and adaptive step acceptance,
  fixed-geometry ejector off-design mode, and turboexpander nozzle capacity and
  IGV flow function.
- Reservoir and PVT: generalized Rs/Rv material-balance history estimates,
  measured component history replay and fitting, and calibrated EOS checkpoints.
- Other: older `.neqsim` files load correctly, the electrolyzer water balance
  and Faradaic modes are conserved, Fuller diffusion volumes are corrected,
  `EmissionsTracker` uses the IPCC AR5 methane GWP (28), and analyser
  sample-system screening is added.
- Retains Python 3.10-3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.27.0
```

Use conda when you want OpenJDK installed with the package:

```bash
conda install -c conda-forge neqsim=3.27.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```
