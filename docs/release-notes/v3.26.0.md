# NeqSim Python 3.26.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the NeqSim Java 3.26.0 engine for Java 17 or newer. This release
  also carries all changes from NeqSim Java 3.25.0.
- Thermodynamic fixes: wet gas-condensate flashes recover a missing aqueous
  phase, phase mass fractions are derived from conserved inventory, pure-fluid
  saturation enforces domain guards with a corrected hydrocarbon dew
  equilibrium, and CPA and electrolyte-CPA phase state is isolated across
  clones. Electrolyte derivative consistency and the CO2/KCl response are
  corrected.
- Standards and data: the ISO 6976:2016 60 F air compression factor is
  corrected, unsupported ISO 6976 reference temperatures are rejected, and the
  DEA component identity is reconciled with the Henry source inventory.
- E300 fluid files: `VCRIT` is written in m3/kmol and `ZCRIT` as a
  dimensionless value, and `VCRIT` is converted on read.
- Process fixes: heater input specifications are invalidated when changed,
  distillation terminal duties are calculated from published streams, pump
  best-efficiency-point and operating status follow the requested speed, and
  compressor speed solves report consistent results and convergence.
- Pipeline and network: signed-face complementarity and transitions, an
  experimental non-equilibrium post-pigging film transfer model, explicit
  surface temperature profile units, and fail-closed handling of mapped
  compressor errors and incomplete pump operating points.
- New capability: catalytic reforming balance and complete TBP-table blending
  for refinery studies, plus ANP Annex XX profit-oil share tables.
- Internal: the Jama linear-algebra dependency is removed in favor of EJML.
  Java code that used Jama matrices in extension hooks must migrate to EJML
  `SimpleMatrix`; the Python API is unchanged.
- Retains Python 3.10-3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.26.0
```

Use conda when you want OpenJDK installed with the package:

```bash
conda install -c conda-forge neqsim=3.26.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```
