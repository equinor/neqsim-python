# NeqSim Python 3.24.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the NeqSim Java 3.24.0 engine for Java 17 or newer.
- Thermodynamic fixes: flash calculations recover conservative condensate
  splits after an endpoint collapse, exact-zero mole fractions are preserved
  through dependent property calculations, and the unused legacy TP flash
  solver is deprecated in favor of the maintained solver path.
- Process fixes: `ProcessSystem` recycle diagnostics and minimum-flow spill
  handling are corrected against the separator limit basis, and
  `MultiStreamHeatExchanger2` reports solver status and flags an infeasible
  approach temperature instead of returning a silently wrong result.
- Distillation fixes: shortcut columns reject invalid reflux ratios and stage
  counts, and direct terminal specifications report physically consistent
  residuals.
- Pipeline and network: multiphase chokes follow a new
  `TabulatedValveCharacteristic`, Beggs and Brill pipe-flow solves fail closed
  instead of returning an unconverged result, and field-scale pipeline
  networks gain per-edge Beggs-Brill/two-fluid steady hydraulics alongside new
  inflow-control-device, inflow-control-completion, and subsea
  separation-station screening models.
- New capability: `SealGasSupplyConditioning` screens seal-gas supply dew
  point margin for compressor dry-gas seal systems.
- Internal: the Jama linear-algebra dependency is replaced with EJML.
- Retains Python 3.10-3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.24.0
```

Use conda when you want OpenJDK installed with the package:

```bash
conda install -c conda-forge neqsim=3.24.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```
