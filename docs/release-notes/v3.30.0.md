# NeqSim Python 3.30.0

NeqSim Python 3.30.0 bundles the NeqSim Java 3.30.0 engine and refreshes
the Java type stubs and offline API manifest available to Python users.

## Highlights

- Hydrate calculations converge for the CO₂/NaCl/MEG brine case at 44 bara.
  This release also updates CPA model selection and Pitzer parameters for MEG.
- Cryogenic calculations include fixes for Leachman hydrogen and GERG-2008
  flashes.
- PVT calculations use corrected volume conventions in differential liberation
  and constant-mass expansion and flash separator oil at stock-tank conditions.
- Two-fluid pipelines report outlet pressure at the physical outlet face.
  Beggs–Brill calculations account for gravitational energy in the energy balance.
- Process studies include well-to-export dynamics with parallel compressor
  protection and plant shutdown, and dry gas seal vent studies for normal
  operation and failure cases.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.30.0
```

The matching conda-forge package can be installed once it is published:

```bash
conda install -c conda-forge neqsim=3.30.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```

## Quick Start

```python
from neqsim.thermo import TPflash, fluid, printFrame

natural_gas = fluid("srk")
natural_gas.addComponent("methane", 0.85)
natural_gas.addComponent("ethane", 0.10)
natural_gas.addComponent("propane", 0.05)
natural_gas.setTemperature(25.0, "C")
natural_gas.setPressure(60.0, "bara")
natural_gas.setMixingRule("classic")

TPflash(natural_gas)
printFrame(natural_gas)
```
