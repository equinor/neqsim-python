# NeqSim Python 3.23.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the NeqSim Java 3.23.0 engine for Java 17 or newer. There were no
  NeqSim Python 3.21.0 or 3.22.0 releases, so this release also carries all
  changes from NeqSim Java 3.21.0 and 3.22.0.
- Component database: 132 new components in `COMP.csv` with matching UMR-PRU
  parameters, 228 data defects corrected, and a completed UMR-PRU UNIFAC group
  table. UNIFAC group storage and PSRK loading are restored.
- Process flowsheets: automatic recycle insertion with `makeRecycles()` and
  `setAutoRecycles()` on `ProcessSystem` and `ProcessModel`, plus a faster,
  more robust Wegstein recycle update and corrected Gibbs-reactor mass
  conservation.
- Unit conversions: unit-conversion APIs were refactored onto a shared,
  explicit conversion path so results stay consistent across modules.
- Multiphase pipe flow: `TwoFluidPipe` gains an equilibrium energy balance,
  bounded Andritsos-Hanratty interfacial friction, a steady-consistent
  transient solver, and slug-film coupling with experimental validation.
- New capabilities: fire-water and deluge coverage design, heat-exchanger tube
  fouling coupled to thermal-hydraulic rating, pluggable separator entrainment
  models, an opt-in caloric alpha for CPA water heat capacity, solid-hydride
  hydrogen storage capacity/fugacity screening, rotor-unbalance assessment
  (API 671 / ISO 21940), and living tasks for continuous task solving and
  monitoring.
- Thermodynamic fixes: the 100-component limit in the Michelsen phase envelope
  is removed, DIPPR-101 vapour-pressure dispatch is restored, the hydrate TP
  flash solves for the equilibrium temperature, SAFT flash phase fractions are
  consistent with the final K-values, Soreide-Whitson salinity is propagated
  correctly, and the ammonia and Span-Wagner CO2 reference EOS results are
  corrected.
- Process fixes: JSON-built compressors no longer ignore `polytropicEfficiency`,
  JSON stream inlet wiring is corrected, and separator outlet nozzles and wall
  thickness are sized from the final design.
- Retains Python 3.10–3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.23.0
```

Use conda when you want OpenJDK installed with the package:

```bash
conda install -c conda-forge neqsim=3.23.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```
