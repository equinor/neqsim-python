# NeqSim Python 3.28.0

NeqSim Python is the Python interface to the NeqSim engine for thermodynamic
calculations, physical properties, process simulation, and PVT analysis from
Python and Jupyter notebooks.

## Highlights

- Bundles the official NeqSim Java 3.28.0 release engine for Java 17 or newer.
- Thermodynamics: restores difficult pressure-entropy flash roots and accelerates
  bracketed saturation flashes.
- Compressors and dynamics: keeps chart power local to each compressor run, adds
  oscillation analysis and compressor load limiting, and extends time-series
  process replay and TEG absorber handling of hydrocarbon liquid.
- Reservoir and PVT: improves native fixed-cell depletion, CVD component
  accounting, and preservation of liquid and aqueous inventories.
- Pipelines: extends phase-resolved boundary accounting, hydrostatic pressure
  moments, gravity-energy conservation, gas-only pressure outlets, and liquid
  pool and wall-inventory handling during restart screening.
- Engineering drawings: exposes DEXPI 2.0.1 PFD and instrumented P&ID review
  packages, quality review, and simulation handoff through the Java API
  (`jneqsim`). Review drawings still require engineering verification.
- Refreshes the bundled Java API manifest, type stubs, and component-name
  metadata for the 3.28.0 engine.
- Retains Python 3.10-3.14 support and the existing NeqSim Python API.

## Install

Use pip when you already have Java installed:

```bash
pip install --upgrade neqsim==3.28.0
```

The matching conda-forge package can be installed once it is published:

```bash
conda install -c conda-forge neqsim=3.28.0
```

Requirements:

- Python 3.10 or newer.
- Java 17 or newer for pip installs. Download Java from
  [Adoptium](https://adoptium.net/).
- Conda installs include OpenJDK through conda-forge.

Verify the installed package version without starting the JVM:

```bash
python -c "from importlib.metadata import version; print(version('neqsim'))"
```

## Quick Start

```python
from neqsim.thermo import TPflash, fluid, printFrame

natural_gas = fluid("srk")
natural_gas.addComponent("methane", 0.85)
natural_gas.addComponent("ethane", 0.10)
natural_gas.addComponent("propane", 0.05)
natural_gas.setTemperature(25.0, "C")
natural_gas.setPressure(60.0, "bara")
natural_gas.setMixingRule("classic")

TPflash(natural_gas)
printFrame(natural_gas)
```
